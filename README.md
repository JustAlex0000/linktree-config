# Linktree Config

A React + Vite JavaScript starter for a personal link page customized through a JSON configuration file. The project currently contains the official Vite demo; link-page features will be built incrementally.

## Start development

Open this folder in VS Code. In its terminal, run:

```sh
npm run dev
```

Open the local URL printed in the terminal. Saved changes appear automatically.

Dependencies are already installed. After downloading the project on another machine, run `npm ci` first. Node 24 is recommended.

## Files to learn first

- `src/App.jsx`: the main React component and starter counter.
- `src/App.css`: component styles.
- `src/index.css`: page-wide styles.
- `src/main.jsx`: mounts the React app in the page.
- `public/`: static files; the editable config will go here when implemented.

## Check and build

```sh
npm run lint
npm run build
npm run preview
```

The build goes into `dist/`. GitHub Pages configuration will be added when the repository and hosting path are chosen.

Scaffolded with the official [React JavaScript template from Vite](https://vite.dev/guide/).
